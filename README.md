# sre-til

Today I learned: short daily notes from an SRE's study log.

One file per note, grouped by topic. Notes are written in my own words, link the source, and end with how I'd use it in production. The bigger builds live in [sre-tools](https://github.com/AnuRadhaRao/sre-tools).

## Topics

- [Kubernetes](kubernetes/)
- Terraform
- AWS
- CI/CD
- Observability
- Azure

## Format

```
# Title
Date · Source (link)

What I learned, in 3 to 5 sentences.

## How I'd use it
One or two lines on where this matters in real systems.
```
